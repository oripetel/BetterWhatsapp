# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the
work. Harassment, personal attacks and sharing other people's private messages
aren't tolerated.

Report unacceptable behavior privately through
[GitHub Security Advisories](https://github.com/oripetel/BetterWhatsapp/security/advisories/new)
or by contacting the maintainer on GitHub (@oripetel). Reports are handled in
confidence.
